# Legacy Documentation

This directory contains inactive Stage 3 PCA, Stage 4 clustering, and early
project-design material. It is retained for historical context and possible
future reactivation.

The active pipeline ends at Stage 2, with temporal and spatial composite
workflows consuming prepared products. Do not use the files in this directory
as current contracts.

Legacy material includes:

- `002_pca_feature_matrix.md`
- `003_clustering_strategy.md`
- `stage3_event_feature_pca.md`
- `stage4_event_feature_clusters.md`
- `pca_diagnostics.md`
- `cluster_interpretation.md`
- `HW_analysis_description.md`

The Stage 3 and Stage 4 scheduler files remain under `schedulers/` for
historical reference, but their script paths no longer identify active
entrypoints. Do not submit them unless the workflows are explicitly
reactivated, their paths and contracts are repaired, and focused tests are
restored to the active suite.
